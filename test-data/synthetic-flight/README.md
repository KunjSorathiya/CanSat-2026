# Synthetic flight

> [!WARNING]
> **Nothing in this directory is flight data.** It was generated by
> [`analysis/synthetic_flight.py`](../../analysis/synthetic_flight.py) from the parameters in
> [`truth.json`](truth.json). No vehicle produced any of it.

It exists so the post-flight analysis can be written, tested and rehearsed before the launch, in
the exact formats a real flight leaves behind.

| File | Format | How it was made |
|---|---|---|
| [`sd-flight.csv`](sd-flight.csv) | The onboard log, as `tools/read_flight_log.py` extracts it — the firmware's column header, one row per transmitted packet | The generator, row by row in `TelemetryBuilder::sd_line()`'s layout |
| [`ground-packets.txt`](ground-packets.txt) | What the ground station heard: one packet per line | The same packets, with 1.5 % lost at random and one lost mid-descent on purpose |
| [`ground-telemetry.csv`](ground-telemetry.csv) | The ground station's parsed CSV | `ground-packets.txt` through the **real** `main.py replay --export` |
| [`truth.json`](truth.json) | The answers | Every parameter, and the events and rates derived from them |

## The flight

The sealed flight image's schedule: telemetry at 1.43 Hz through the command window, `MAX_RATE`
at 95 s, recalibration and arming, then the rich/lean/lean pattern at 3.11 Hz. A drone lift at
3 m/s to 30.48 m, a 20 s hover, release, 0.4 s of free fall, and a canopy descent integrated from
the drag equation `simulations/descent.py` uses — 0.500 kg under an 80 cm canopy with Cd 0.75 —
at a terminal rate of **4.74 m/s** in 31 °C air. Landing, tipping over, and the post-impact window.

Along the way it carries the things a real log has and a tidy fixture would not: a few
uncalibrated rows reading ~23 m at power-on, **the firmware's ISA-formula altitude bias** on a hot
day, a pendulum swing and a spin under the canopy, wind drift in the GPS, GPS fixes held between
1 Hz updates, drone noise in the microphone, and transients that fall between packets.

## Regenerating it

```bash
python analysis/synthetic_flight.py
```

The output is deterministic. `analysis/tests/` fails if the committed `sd-flight.csv` or
`ground-packets.txt` is not what the generator produces.
