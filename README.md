# CanSat 2026

CanSat competition project.

## Project Structure

- `avionics/` — Avionics and onboard electronics
- `firmware/` — Flight computer and firmware
- `ground-station/` — Ground station software
- `mechanical/` — Mechanical design and CAD
- `electrical/` — Schematics and PCB
- `simulations/` — Simulations and analysis
- `documentation/` — Engineering documentation
- `test-data/` — Test results and datasets
